# tcgplayer-import
A tool for generating CSV files to import to TCGplayer.

Type simplified card names, pick the exact printing (with image preview), set quantity, condition and price, then export a CSV in TCGplayer's seller inventory import format. Supports Magic: The Gathering, Star Wars Unlimited and Cyberpunk TCG.

## Getting started (Windows)
1. Click the green **Code** button, then **Download ZIP**, and extract it (or download `tcgplayer-importer.zip`).
2. Double-click **Start TCG Importer.bat**. If Windows says "Windows protected your PC", click More info > Run anyway.
3. The tool opens in your browser. Click **Build catalog…**, pick a game and the sets you sell, and click Build.
4. Add cards, then **Export CSV**. In TCGplayer Seller Portal: Pricing > Import To Staged > choose the file. Check the staged cards, then Move To Live.

See README.txt for the full guide (pricing rules, conditions, loading lists).

Card IDs come from an unofficial TCGplayer lookup that could change without notice. Prices come from tcgcsv.com.
